# ALASFOUR LEADS

MVP لإدارة وفرز إعلانات العقارات والملاك المحتملين.

## Supabase SQL

نفّذ هذا الكود في Supabase SQL Editor:

```sql
create table if not exists leads (
  id bigint generated by default as identity primary key,
  title text not null,
  location text default '',
  property_type text default '',
  price text default '',
  advertiser text default '',
  phone text default '',
  url text default '',
  description text default '',
  classification text default '',
  owner_score integer default 0,
  status text default 'جديد',
  created_at timestamptz default now()
);

alter table leads enable row level security;

create policy "public read leads"
on leads for select
to anon
using (true);

create policy "public insert leads"
on leads for insert
to anon
with check (true);
```

## Vercel Environment Variables

أضف:
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY

لا تضع Service Role Key داخل المشروع.
